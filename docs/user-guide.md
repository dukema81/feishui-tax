## 1. 系统定位

飞税税务管理系统面向集团多主体税务管理场景，覆盖 **发票 → 抵扣 → 申报 → 缴款 → 凭证 → 分析 → 风险** 全链路，内置 2026 年现行税法口径的计算引擎。

## 3. 页面导览（11 页）

### 3.1 工作台

- 8 个 KPI：主体数、销项 / 进项 / 应纳增值税、申报税额、待缴税额、待申报 / 逾期、待处理风险；
- 近 6 期销项与申报税额双柱趋势图；
- 本期税额构成排行（企税 / 增值税 / 个税 / 附加）；
- 待办申报表（逾期标红，点击跳转申报页）；
- 纳税主体概况、未处理风险卡、通知公告。

### 3.2 发票管理

- 筛选：类型（销项 / 进项）、期间、主体、关键词（发票号 / 销方 / 购方）；
- 汇总条实时显示张数、金额、税额；
- 点击行打开详情弹窗：票面字段、**三流一致校验结果**、风险提示；
- 「+ 新增发票」：选类型 / 主体 / 票种 / 税率，输入金额（可选含税口径），系统自动算税；有 `invoice.void` 权限可在详情中作废；
- 「导出 CSV」下载当前筛选的发票台账。

### 3.3 进项抵扣

- KPI：进项合计、已认证可抵扣、待认证、张数；
- 按税率分布、认证状态两张表；
- 供应商集中度 Top10；
- 明细区可逐张点击「认证」（校验销方税号与作废状态，不合规拒绝）。

### 3.4 纳税申报

- 筛选期间 / 主体 / 状态；汇总条显示单数、应纳税额、待缴；
- 操作列按状态流转：待申报 →「申报」；已申报 →「缴款」（缴款后自动生成凭证）；
- 「详情」查看计税明细与关联凭证；
- 「+ 新建申报」：选主体 / 税种 / 期间 → 点「试算」从源数据自动算出应纳 → 保存。

### 3.5 税种计算器（14 个模型）

增值税单票 / 小规模简易 / 一般计税、附加税费、企税年度 / 季度、个税综合 / 工资 / 年终奖、印花税、房产税、土地使用税、综合税负率、滞纳金。填写左侧参数 → 点「计算」，右侧显示核心结果（大字）与完整字段表。计算不入库，可反复调整。

### 3.6 税负分析

- 期间切换后展示：营业收入、税额合计、综合税负率、涉及税种；
- 税额趋势双柱图、税额构成（含占比条）、主体税负排行、进项税率结构、供应商 Top10；
- 导出发票台账 CSV。

### 3.7 风险预警

- 清单按等级排序（险 → 警 → 提），每条含规则码、权重、明细；
- 待处理条目可填写处置说明后「标记已处理」或「忽略」；
- 「重新扫描」按当前期间重跑规则引擎，新增风险即时入列；
- 筛选条显示风险指数（0~100）。

### 3.8 纳税主体

8 家主体档案：纳税人身份、行业、法人、人员、资产，小微 / 高新标识；点击行查看详情弹窗（含当期销项 / 进项 / 应纳统计）。

### 3.9 凭证台账

涉税凭证（申报缴款自动生成 + 手工）与合同台账；KPI 显示印花税合计与待缴数。

### 3.10 政策法规

- 税率速查卡（13% / 9% / 6% / 3% / 1% / 5% / 0.03% / 1.2%）；
- 政策清单按税种 / 关键词检索，点击查看全文与标签。

### 3.11 系统管理（5 个页签）

1. **组织用户**：8 部门 + 13 用户一览；
2. **角色权限**：6 角色的权限点矩阵；
3. **税务参数**：城建税档、六税两费减半开关、滞纳金率等 7 项可配参数；
4. **接口密钥**：创建 API Key（只显示一次，务必复制保存）、查看对接说明；
5. **操作日志**：全部敏感动作审计。

## 4. 常见问题

**Q1：申报期限怎么定？** 系统按税种自动推算（增值税等月度税种为次月 15 日，企税年度为次年 5 月 31 日），到期前 3 天（可配）工作台提醒，逾期标红。

**Q2：缴款后凭证从哪来？** 缴款确认后系统自动生成「借：应交税费 / 贷：银行存款」凭证，可在凭证台账查看。

**Q3：进项发票为什么认证不了？** 三种情况会被拒绝：销方税号缺失、发票已作废、非进项发票。先在发票管理核实票面信息。

**Q4：三流不一致是什么意思？** 指发票流（开票双方）、合同流（合同签订方与金额）、资金流（付款方）交叉比对不一致。系统自动出「险」级风险，需人工核查是否虚开或合同变更未同步。

**Q5：小微企业税率怎么算？** 应纳税所得额 ≤300 万、从业 ≤300 人、资产 ≤5000 万，减按 25% 计入 × 20%，实际税负 5%。纳税主体档案中维护小微标识后，申报试算自动套用。

**Q6：外部系统怎么对接？** 系统管理 → 接口密钥创建 Key（read / write / full），请求头带 `X-Tax-Key`；增量数据用 `/api/sync`；完整契约见《API 接口契约》文档或在线 `/api/apidoc`。

## 5. 操作技巧

- 工作台 KPI 卡点击数字即跳转对应页面；
- 计算器结果区的字段表可直接复制给业务方做测算说明；
- 发票 / 申报列表均可导出 CSV（UTF-8 BOM，Excel 直接打开不乱码）；
- 移动端（≤820px）侧边栏自动折叠为顶部横排。
