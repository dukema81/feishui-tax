## 2. 单元测试明细（tests/test_unit_tax.py，34 例）

### 2.1 增值税（9 例）

- 单票税额：不含税 13% → 税额 13000 / 价税合计 113000；含税反向拆分一致；
- 9%、6% 档位税额；
- 非法税率（7%）正确抛出 TaxError；
- 小规模：季 25 万免征、季 35 万按 1% 缴 3500、月度 10 万起征点边界（99999 免 / 100001 征）；
- 一般计税：销项 130000 − 进项 65000 = 应纳 65000；进项大于销项形成留抵 52000。

### 2.2 附加税费（3 例）

市区减半 6000（城建 3500 + 教附 1500 + 地教 1000）、市区全额 12000、县城镇 10000。

### 2.3 企业所得税（4 例）

小微 280 万 → 14 万（实际 5%）、标准 25% → 70 万、高新 15% → 42 万、弥补亏损后计税基数 60 万。

### 2.4 个人所得税（5 例）

综合所得 20 万 → 23080（20% 档，速算 16920）、3 万 → 900（3%）、工资薪金（年 36 万 − 三险一金 5.4 万 − 专项附加 2.4 万 → 应纳 27480）、年终奖 10 万单独计税 → 9790、择优模式返回 separate/merge 双结果。

### 2.5 财产行为税（6 例）

印花税买卖合同 0.03% → 300、借款合同 0.005% → 50、含税金额自动剔除增值税；房产税从价（500 万原值、30% 减除）→ 42000、从租 12%；土地使用税 1000㎡ 三级 → 18000、自定义单价 9 元 → 9000。

### 2.6 风险与工具（7 例）

三流一致通过 / 不一致检出、风险打分 70 分定级「高」、税负偏离预警、滞纳金 1 万 × 10 天 → 50、申报期限推算、逾期判定。

### 2.7 校验与权限（2 组）

主体 / 申报单必填校验；权限通配 `*`、精确匹配、6 角色完整性。

## 6. 测试中发现并修复的缺陷

| # | 缺陷 | 修复 |
| --- | --- | --- |
| 1 | dashboard 排序 KeyError（declarations 主键是 no 非 id） | SELECT 补 no 列，lambda 改用 x["no"] |
| 2 | 列表接口返回结构不统一（有的裸数组） | 统一为 {list,total}，9 个接口改造 |
| 3 | /api/calc 入参不兼容 camelCase 且缺别名 | 重写参数兼容层，14 种 kind + 别名表 |
| 4 | vat_general 进项传列表时报 'str' has no get | inputs 支持合计数与明细列表双形态 |
| 5 | late_fee 传 rate=None 时费率变 0 | dec 兜底默认万分之五 |
| 6 | 个税年度基本减除费常量缺失 | 补 IIT_SALARY_THRESHOLD=60000 |
| 7 | risks/scan 500（D 未定义） | server.py 补 D = Decimal 别名 |
| 8 | 发票认证接口只收 nos 数组 | 兼容 {no} 单张 |
| 9 | 风险指数显示 [object Object] | 前端解包 {score,grade,count} |
| 10 | 工作台 HTML 拼接三元优先级错误导致 KPI 区丢失 | 三元表达式补括号 |
| 11 | 种子无 reader 角色账号 | 补 reader01 演示账号 |
